## DCrux 1.4.1

**Phone:** download `DCrux-1.4.1.apk` below, or let the app update itself (Settings → App update).
**Computer:** Windows `DCrux-1.4.1-windows-x64-setup.exe` (or the `.msi`), Linux `DCrux-1.4.1-linux-x64.deb` or `DCrux-1.4.1-linux-x64.tar.gz` (unpack and run `DCrux/bin/DCrux`).

### Changed
- **Sync is now immediate.** Once two devices are paired (by QR code or typed code), opening the app syncs at once, and while it is open a change made on one device shows up on the other within seconds, with nothing to press.
- **And lighter.** Devices no longer download everything on a timer. Each open app keeps one idle connection on which the service says "something changed"; data moves only when it actually has, and a device that is already up to date is told so in a few bytes. A phone that is put away stops listening.
- **Windows installers** (`.exe` and `.msi`) are now built for each release.

### Good to know
- Changes are sent about three seconds after you make them, so that several in a row travel together.
- The Windows build is made and started by an automated check on GitHub; it has not yet been used by hand. Tell us what you find.
