## DCrux 1.4.2

**Phone:** download `DCrux-1.4.2.apk` below, or let the app update itself (Settings → App update).
**Computer:** Windows `DCrux-1.4.2-windows-x64-setup.exe` (or the `.msi`), Linux `DCrux-1.4.2-linux-x64.deb` or `DCrux-1.4.2-linux-x64.tar.gz` (unpack and run `DCrux/bin/DCrux`).

### New
- **Settings, redesigned.** Everything is grouped under short headings (Study, Crux AI, Sync, App, Your data, About). Each row shows what is set now, and tapping it slides its controls up from the bottom.
- **Pair with a 4-character code.** Open Settings → Sync across devices on a device that is syncing: the QR code sits in the middle of the sheet with a 4-character code under it. Type those four characters on the other device (or scan the QR code with a phone) and the two are paired. A computer can now join a phone this way.

### Changed
- **The sync service keeps nothing on disk.** It only passes your (already encrypted) data between your devices, holding the latest copy in memory so a device that was off can catch up. Your devices are where the data lives.
- **Sync is quicker.** A change is sent well under a second after you make it (it used to wait about three seconds).

### Good to know
- The 4-character code is not the key to your data. It works once, lasts a few minutes, and a wrong guess replaces it. It is only used so the two devices can pass the real key between them safely.
- Devices already paired stay paired. Update all of them when you can.
- The Windows build is made and started by an automated check on GitHub; it has not yet been used by hand.
