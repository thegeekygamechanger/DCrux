## DCrux 1.4.6

**Phone:** download `DCrux-1.4.6.apk` below, or let the app update itself (Settings → App update).
**Computer:** Windows `DCrux-1.4.6-windows-x64-setup.exe` (or the `.msi`), Linux `DCrux-1.4.6-linux-x64.deb` or `DCrux-1.4.6-linux-x64.tar.gz` (unpack and run `DCrux/bin/DCrux`).

This release is about the computer app being lighter and quicker. Nothing about how it looks or behaves has changed.

### On a computer
- **Opens about twice as fast.** Measured on a modest laptop: the first screen in about 1.2 seconds instead of 2.5. This applies from the second start: the first start after installing or updating is as before, and during it the app quietly prepares what makes the later ones quick.
- **Uses about 120 MB less memory.** About 300 MB instead of 420 MB on the same laptop, and the app's own share of that falls from about 300 MB to about 140 MB. Memory it no longer needs is handed back while it runs.
- **A calm start.** A small DCrux card appears the instant you start the app, and the window then arrives already drawn and fades in, instead of opening blank and blinking.

### Good to know
- The quick start needs the app's folder to be writable, which it is for the Windows installer, the `.tar.gz`, and anything installed in your home folder. Installed system-wide from the `.deb`, the app keeps the memory savings but opens at the old speed for now.
- The phone app is unchanged in this release apart from its version number.
- The Windows build is made and started by an automated check on GitHub; it has not yet been used by hand.
